## 🚀 Quick Start & Development

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or higher)
- npm (v9.x or higher)

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

---

## 🛠️ Production Build & GitHub Pages Deployment

To compile static assets:
```bash
npm run build
```
The build artifacts are saved in `dist/` with relative URLs (`./assets/...`), ensuring 100% compatibility with GitHub Pages both at root domains and repository subpaths.

An automated GitHub Actions workflow is provided in `.github/workflows/deploy.yml`. Push to your `main` branch to trigger immediate deployment.
